# UI/UX Pro Design System & Guidelines

## Core Principles

1. **Precision & Hierarchy**:
   - Every layout must have intentional spacing, clear visual hierarchy, and high contrast.
   - White / neutral main backgrounds paired with deliberate corporate accents (e.g. Deep Corporate Purple `#6d28d9`).

2. **Sharp Edges & Minimalist Geometry**:
   - Zero or minimal border-radius (`0px` - `4px`) for a sharp, executive, precision engineering / corporate feel.
   - Crisp 1px solid borders (`#e2e8f0`, `#cbd5e1`) instead of heavy glows or blurry shadows.

3. **Typography**:
   - Clean sans-serif corporate typefaces (`Inter`, `Plus Jakarta Sans`, `system-ui`).
   - Monospace for IDs, financial amounts, and timestamps (`JetBrains Mono`).
   - Micro-labels in uppercase with deliberate letter-spacing (`0.05em`).

4. **Component Design**:
   - High-contrast form inputs with sharp focus states.
   - Clean tables with alternating or subtle line dividers.
   - Printable, professional ID / credential cards.
